# Lin-go

> ⚠️ **Work in progress.** This project is under active development and its API may change without notice. Not yet ready for production use.

Lin-go aims to be a fast, dependency-free Italian tokenizer written in Go, with rule-based handling of abbreviations, acronyms, dates, numbers, units, URLs, emails, and punctuation.

## Status

- Core tokenizer and rule engine are in early development ([tokenizer/](tokenizer/), [rules/](rules/)).
- API, rule set, and behavior are expected to change.
